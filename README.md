# Meu Primeiro Portfólio 🚀

Este é o meu primeiro repositório no GitHub! Ele armazena uma página simples de portfólio pessoal que criei para iniciar meus estudos em desenvolvimento web.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação da página.
- **CSS3:** Estilização e design responsivo.

## 🧠 Aprendizados
Com este projeto, aprendi a:
- Criar a estrutura básica de um documento HTML.
- Aplicar estilos visuais e cores usando CSS de forma externa.
- Criar e gerenciar um repositório diretamente pela interface do GitHub.
